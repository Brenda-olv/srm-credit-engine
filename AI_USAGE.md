# AI Usage Report

Este documento descreve de forma transparente como ferramentas de Inteligência Artificial foram utilizadas durante o desenvolvimento deste projeto.


## Objetivo do uso de IA

A IA foi utilizada como apoio pontual para esclarecer dúvidas técnicas, auxiliar em cálculos e acelerar a implementação de algumas funcionalidades específicas no projeto.

O foco principal do desenvolvimento continuou sendo o entendimento e implementação manual do código.

## Uso prático da IA no projeto

###  Cálculo de métricas e taxas

A IA foi utilizada para auxiliar na compreensão e implementação de algumas métricas do dashboard, como:

- Definição e interpretação de “spread médio”
- Contagem de operações por moeda (ex: USD)
- Lógica de agregação de dados a partir de listas mockadas

Isso ajudou a transformar os dados da tabela em indicadores consistentes no dashboard.


## Decisões mantidas pelo desenvolvedor

Todas as decisões finais foram tomadas pelo desenvolvedor, incluindo:

- Estrutura do projeto (core, features, shared)
- Modelagem dos dados de transações
- Lógica de negócio do dashboard
- Implementação da interface e UX
- Integração entre tabela e dashboard

## Resultado do uso de IA

O uso de IA contribuiu principalmente para:

- Melhor compreensão de conceitos de negócio
- Redução de erros em lógica de cálculo 

## Observação final

A IA foi utilizada apenas como ferramenta de apoio técnico, sem substituir o processo de desenvolvimento ou o entendimento das soluções implementadas.
